# Задание: Синтаксис YAML для GitHub Actions

## Цель
Освоить структуру YAML: пары ключ–значение, типы данных, вложенные объекты, списки, кавычки, специальные символы и многострочные блоки. Применить конструкции в конфигурациях CI/CD.

## Задание 1. Базовые элементы YAML
Создать конфигурационный YAML-файл, содержащий строки и числа, true и false, null, комментарии, блочный массив минимум из трёх элементов, отступы в два пробела без табуляции.

**Реализация:** [simple-config.yml](simple-config.yml).

## Задание 2. Вложенные структуры и специальные символы
Создать YAML-документ с вложенными объектами, строкой со специальными символами в кавычках, примером экранирования апострофа удвоением, блочным и inline-массивом.

**Реализация:** [nested-structure.yml](nested-structure.yml).

## Задание 3. Продвинутые конструкции
Создать сложную структуру с вложенностью более трёх уровней, списками объектов, inline-массивами, многострочным блоком |- и параметрами CI/CD workflow.

**Реализация:** [workflow-spec.yml](workflow-spec.yml).

## Дополнительная часть
Настроить GitHub Actions для проверки при push, pull request и вручную. Скрипт: scripts/validate_yaml.py. Workflow: .github/workflows/yaml-validation.yml.

## Чек-лист

- [ ] Отступы сделаны пробелами, табуляция отсутствует.
- [ ] Специальные символы оформлены корректно.
- [ ] Присутствуют блочные и inline-массивы.
- [ ] Есть многоуровневая структура.
- [ ] Workflow GitHub Actions добавлен.
- [ ] Проверка в Actions завершилась успешно.
